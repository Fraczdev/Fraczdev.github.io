What is Mee7?

Mee7 is a lightweight Slack bot that provides a collection of simple utility and entertainment commands directly inside Slack. Everything is accessed through Slack slash commands, so there is no separate interface required to use the bot.

The bot is designed to be straightforward and responsive while keeping its functionality intentionally simple. It can check latency, retrieve random facts, fetch dog images, provide jokes, and return random quotes.

Commands

/mee7-ping

Checks Mee7's response latency and returns the time taken for the bot to respond.

/mee7-catfact

Retrieves a random fact about cats.

/mee7-dog

Retrieves a random dog image.

/mee7-joke

Retrieves a random joke while filtering inappropriate categories.

/mee7-fact

Retrieves a random useless fact. Unsuitable results are automatically discarded and replaced.

/mee7-quote

Retrieves a random quote and its author.

/mee7-help

Displays the available Mee7 commands and their purpose.

Example

Mee7 operates directly inside Slack. For example, running /mee7-ping produces a response similar to:

Slack — Mee7 
/mee7-ping

Pong!
Latency: 42ms
Slack — Mee7 
/mee7-fact

Useless Fact:
Bananas are berries, but strawberries aren't.

Content Safety

Mee7's joke command uses JokeAPI's safe mode and explicitly excludes several inappropriate categories. The fact command also performs basic content filtering.

If an unsuitable result is returned, Mee7 automatically retries the request instead of displaying the result to users. Requests are limited to a fixed number of attempts to prevent an indefinite retry loop.

How it works

Mee7 is built with Node.js and the Slack Bolt framework. It uses Slack Socket Mode to receive slash-command events and external APIs to retrieve dynamic content such as facts, jokes, quotes, and images.

The bot does not require users to interact with a separate website. This page exists as a public overview and demonstration of Mee7's functionality.
